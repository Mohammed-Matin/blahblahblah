# AIHub.cs

AIHub.cs is a clean, modern dashboard designed specifically for computer scientists and developers to track the latest AI updates, discover free APIs, and explore essential AI development frameworks.

## Tech Stack
- React
- Vite
- Tailwind CSS (v4)
- Lucide React (for icons)

## Getting Started

1. Navigate to the project directory:
   cd ai-hub

2. Install dependencies:
   npm install

3. Run the development server:
   npm run dev &

4. Build for production:
   npm run build
